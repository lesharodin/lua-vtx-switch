## Lua LED & VTX Race

Скрипт для переключения каналов видеопередатчика и цвета светодиодов с экрана аппаратуры.

### Изменения в v1.0.0

* Добавлен отдельный экран `Color tuner`: подстройка восьми цветов с предпросмотром на ленте, сбросом выбранного цвета и сохранением палитры для каждой модели аппаратуры.
* Параметры `Power Level`, `VTX Mode`, `Bands` и `LED GV` теперь сохраняются сразу при изменении. Палитра Color tuner сохраняется вручную.
* Основные настройки читаются и записываются по единому абсолютному пути `/SCRIPTS/TOOLS/LEDVTXRACE/config.txt` для запусков из Tools и Telemetry.
* Исправлена обработка короткого `RTN` в Telemetry: возврат из вложенных меню сохраняется, а на основном экране больше не пропускается отрисовка кадра. Длинный `RTN` выходит из телеметрии.

### Установка скрипта в EdgeTX

1) Скачать архив `LED-VTX-Race-v1.0.0.zip` со страницы [релизов](https://github.com/lesharodin/lua-vtx-switch/releases/latest) и распаковать. Также можно скачать содержимое репозитория через Code -> Download ZIP.
2) Скопировать содержимое папки `SCRIPTS/TOOLS` из архива в папку `SCRIPTS/TOOLS` на SD карте.
3) На аппаратуре открыть меню `TOOLS` и выбрать `LED & VTX Race`.

Файлы используют отдельные имена `lvtxrc.lua` и `LEDVTXRACE`, поэтому скрипт можно установить рядом с оригинальным `LED & VTX setup` без замены его файлов и настроек.

При обновлении замените Lua-файлы в `SCRIPTS/TOOLS`, включая новый `LEDVTXRACE/tuner.lua`. Если используете запуск из телеметрии, также замените `SCRIPTS/TELEMETRY/lvtxrc.lua`. Сохраните свои `LEDVTXRACE/config.txt` и `colors_*.txt`: не заменяйте существующий `config.txt` файлом с настройками по умолчанию из архива.

### Настройка Betaflight

1) Настроить режим светодиодов в CLI: `set ledstrip_profile = STATUS`.
2) Убедиться, что на вкладке `Receiver` установлен переключатель `Telemetry`.

### Дополнительные опции

В меню настроек скрипта есть параметры `Power Level`, `VTX Mode`, `Bands` и `LED GV`. Они сохраняются автоматически при каждом изменении значения; выход через `RTN` их не отменяет. `Bands` и `LED GV` также сразу применяются в скрипте. Отдельное сохранение нужно только для палитры в `Color tuner` — через `Save & back`.

`VTX Mode`:

* `MSP` - старый режим работы. Скрипт отправляет `MSP_SET_VTX_CONFIG` напрямую в Betaflight, затем сохраняет настройки через `MSP_EEPROM_WRITE`.
* `ELRS` - новый режим для ExpressLRS VTX Administrator. Скрипт читает текущие `Band/Enable`, `Channel` и `Pwr Lvl` из TX-модуля ELRS, записывает изменения туда же и нажимает `Send VTx`.

В режиме `ELRS` дальнейшую отправку выполняет сам TX-модуль ExpressLRS: он рассылает VTX-настройку на FC/RX и, если это разрешено состоянием модели, отправляет MSP-пакет в ELRS TX Backpack. Отдельная настройка Backpack в скрипте не нужна.

Для `VTX Mode: ELRS` можно выбрать `Power Level: -`. В этом случае TX-модуль ELRS не отправляет уровень мощности в VTX-команде, и видеопередатчик продолжает использовать уровень, заданный в Betaflight. В режиме `MSP` скрипт всегда отправляет валидный power level.

В `VTX Mode: ELRS` изменение VTX-канала или `Power Level` применяется сразу после выхода из списка повторным нажатием `Enter`, как в Lua-скрипте ExpressLRS. Кнопка `Save` сохраняет настройки скрипта и применяет выбранные параметры VTX.

Параметр `Bands` выбирает набор каналов в списке VTX. `Analog` показывает все доступные band/channel из скрипта. `HDZero` оставляет только `Raceband 1-8`, `Band E 1`, `Fatshark 1`, `Fatshark 2`, `Fatshark 4` и `Lowband 1-8`. Если TX-модуль ELRS сообщает канал вне выбранного HDZero-списка, скрипт временно показывает этот фактический канал отдельным пунктом, чтобы не потерять текущее состояние VTX Administrator.

Цвет меняется через Global Variable EdgeTX, выведенную в отдельный AUX-канал. Значение постоянно передаётся вместе с обычными RC-пакетами ELRS, а Betaflight одновременно меняет цвет всех заранее настроенных LED. Количество LED и Larson задаются один раз в CLI Betaflight.

`LED GV` выбирает Global Variable EdgeTX от `GV1` до `GV9`. По умолчанию выбрана `GV9`.

#### Быстрое управление цветом через AUX/GV

В примере используется `GV9`, канал `CH9 / AUX5` и 20 светодиодов. Выбранные номера GV и AUX должны быть свободны и не должны участвовать в ARM, полётных режимах или других функциях модели.

В CLI Betaflight выполнить:

```
feature LED_STRIP
set ledstrip_profile = STATUS

color 0 0,0,255
color 1 178,0,255
color 2 359,0,255

led 0 0,0::CT:1
led 1 1,0::CT:1
led 2 2,0::CT:1
led 3 3,0::CT:1
led 4 4,0::CT:1
led 5 5,0::CT:1
led 6 6,0::CT:1
led 7 7,0::CT:1
led 8 8,0::CT:1
led 9 9,0::CT:1
led 10 10,0::CT:1
led 11 11,0::CT:1
led 12 12,0::CT:1
led 13 13,0::CT:1
led 14 14,0::CT:1
led 15 15,0::CT:1
led 16 0,1::CT:1
led 17 1,1::CT:1
led 18 2,1::CT:1
led 19 3,1::CT:1

mode_color 7 0 8
save
```

`mode_color 7 0 8` назначает управление цветом на канал с внутренним индексом 8: это `CH9 / AUX5` при стандартном порядке каналов CRSF. Проверить соответствие нужно на вкладке Receiver Betaflight.

Для Larson Scanner заменить `CT` на `CTO` у всех LED, например:

```
led 0 0,0::CTO:1
```

В EdgeTX открыть настройки текущей модели и на странице `Mixes` добавить:

```
CH9
  Source: GV9
  Weight: 100%
  Offset: 0%
```

После этого в настройках скрипта выбрать:

```
LED GV: GV9
```

Пункты Red, Orange, Yellow, Green, Cyan, Blue, Violet и Magenta устанавливают точные положения виртуального AUX. Выключение ленты можно настроить штатным режимом Betaflight `LEDLOW`. Белый и чёрный отсутствуют в списке `AUX/GV`, поскольку приведённая конфигурация AUX управляет полным кругом Hue при постоянных насыщенности и яркости.

Цвет применяется сразу при листании списка, без нажатия `Save`. Держать Tools-скрипт открытым или запускать его фоном не требуется: после записи GV обычный микс EdgeTX продолжает постоянно передавать соответствующее значение AUX. Кнопка `Save` сохраняет настройки самого скрипта и применяет выбранные параметры VTX.

Если используется другой AUX, число в `mode_color 7 0 N` является внутренним индексом RC-канала:

```
AUX1 / CH5  → 4
AUX2 / CH6  → 5
AUX3 / CH7  → 6
AUX4 / CH8  → 7
AUX5 / CH9  → 8
```

Микс EdgeTX следует назначить на соответствующий канал.

#### Подстройка цветов: Color tuner

В настройках после `LED GV` находится пункт `Color tuner`, открывающий отдельный экран подстройки восьми цветов. Он меняет значение GV для каждого цвета: оттенок можно подобрать под конкретную ленту без изменения CLI-конфигурации.

* Выберите цвет — он сразу появится на ленте.
* Нажмите `Enter` и изменяйте значение энкодером или кнопками. Шаг — 5 единиц GV, при событиях удержания кнопки — 20. Диапазон ограничен значениями от -1024 до 1024.
* Повторный `Enter` завершает редактирование. `MENU` возвращает выбранному цвету исходное значение.
* Пункт `Save & back` в конце списка сохраняет всю палитру и возвращает в настройки. Настройки VTX при этом не отправляются.
* `EXIT` во время редактирования завершает его; вне редактирования — закрывает экран без сохранения всей подстройки. После закрытия снова применяется цвет, выбранный на основном экране.

Например, если `Magenta` выглядит красным, попробуйте уменьшить его исходное значение `973`, наблюдая за лентой.

Подстройка хранится отдельно для каждой модели EdgeTX в файле `SCRIPTS/TOOLS/LEDVTXRACE/colors_<файл модели>.txt`. Переименование отображаемого имени модели не меняет её палитру. Если несколько дронов используют одну модель аппаратуры, палитра у них будет общей. Сохранение требует EdgeTX 2.6 или новее: идентификатор берётся из `model.getInfo().filename` ([документация EdgeTX](https://luadoc.edgetx.org/lua-api-reference/model/getinfo)). При отсутствии идентификатора или ошибке записи экран показывает `No model ID` либо `Save failed` и остаётся открытым.

#### Запуск с экрана телеметрии

Для быстрого доступа к скрипту на экране телеметрии в аппаратурах с ч/б дисплеем:
1) Положить `lvtxrc.lua` из папки `SCRIPTS/TELEMETRY` из архива в папку `SCRIPTS/TELEMETRY` на SD-карте.
2) В настройках модели на странице `DISPLAY` выбрать `Script: lvtxrc` для любого из экранов.

При запуске с экрана телеметрии короткий `RTN` завершает редактирование или возвращает из вложенного меню; на основном экране скрипта он оставляет экран открытым. Для выхода из телеметрии удерживайте `RTN`. При запуске через `TOOLS` короткий `RTN` на основном экране закрывает скрипт.


### Возможные проблемы

* Если нужно управлять VTX через ELRS VTX Administrator, выберите `VTX Mode: ELRS`. В режиме `MSP` скрипт работает как старая версия и не синхронизирует выбранный канал с TX-модулем.
* В режиме `ELRS` канал в меню может автоматически измениться на текущий канал из TX-модуля. Это сделано специально, чтобы скрипт показывал фактическое состояние VTX Administrator.
* Количество LED и overlays скрипт не изменяет. Настройте их заранее через CLI.
* Если цвет немного отличается от ожидаемого, проверьте endpoints канала в Receiver: для правильного преобразования нужны значения около 1000, 1500 и 2000.
